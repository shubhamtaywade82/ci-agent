# @nemesis-oss/ci-agent

Command-line entry point for the Nemesis CI agent.

Part of [ci-agent](https://github.com/shubhamtaywade82/ci-agent): a deterministic-core, advisory-only CI agent. It never merges, and any LLM output is validated and policy-gated before it is acted on.

## Install

```bash
npm install -g @nemesis-oss/ci-agent
ci-agent doctor
```

See the [repository README](https://github.com/shubhamtaywade82/ci-agent#readme) for configuration, the threat model and usage.
